# ScamVerse — The Digital Trust Simulator

ScamVerse is an interactive cybersecurity awareness and scam detection platform designed to help users identify suspicious links, phone numbers, messages, and online scams.

## Features

- **Link Checker:** Analyze suspicious URLs and identify potential warning signs.
- **NumberGuard:** Report and explore suspicious phone numbers.
- **Message Analyzer:** Identify common scam patterns in suspicious messages.
- **Cyber Coach:** Learn cybersecurity and online safety through interactive guidance.
- **Digital Detective:** Interactive scam awareness challenges.
- **Learning Centre:** Improve digital safety knowledge through educational content.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Gemini API (where configured)
- Node.js

## Run Locally

### Prerequisites

- Node.js and npm

### Installation

```bash
npm install --legacy-peer-deps
```

### Environment Setup

Create a `.env.local` file and configure the required environment variables.

```env
GEMINI_API_KEY=your_api_key_here
```

Never commit your actual API key to GitHub.

### Start the application

```bash
npm run dev
```

## Important

ScamVerse provides preliminary scam analysis and cybersecurity awareness. Its results should not be treated as guaranteed security verification.
